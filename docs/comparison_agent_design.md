# Comparison Agent

## Purpose
Synthesizes the outputs of the Market, Customer and Competitor agents to generate a final startup validation.

## Reads
- market_analysis
- customer_analysis
- competitor_analysis

## Writes
- comparison_analysis

## A2A Tools
- get_validation_summary()
- generate_swot()
- generate_recommendations()
- get_feature_matrix()
- get_competitive_advantages()
- get_market_gap_analysis()
- get_innovation_score()

## Output
- Feature Matrix
- SWOT Analysis
- Validation Score
- Innovation Score
- Recommendations
- Summary
