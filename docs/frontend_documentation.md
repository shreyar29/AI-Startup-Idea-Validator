# Frontend Documentation

## 1. UI Architecture Overview
The frontend is a Single Page Application (SPA) built with React 19 and Vite. It is designed to act as an executive dashboard that visualizes the complex JSON intelligence generated by the AI backend.

## 2. Folder Structure
- `src/components/`: Reusable UI elements and individual sections of the intelligence report (e.g., `MarketSection.jsx`, `CustomerSection.jsx`).
- `src/pages/`: Main route views (`Home.jsx`, `Dashboard.jsx`, `Contact.jsx`).
- `src/services/`: API integration and HTTP clients (`api.js`).
- `src/styles/`: Global CSS and Tailwind directives (`index.css`).

## 3. Pages & Routing
Uses `react-router-dom` for client-side navigation.
- **`/` (Home)**: The landing page containing the primary input form where users submit their startup idea.
- **`/dashboard`**: The main intelligence report view. Renders conditionally based on the in-memory validation state.
- **`/contact`**: The contact and support page.

## 4. State Management & API Integration
- **State**: The application largely relies on React `useState` and `useEffect` for local state. The main validation result is passed via React Router's `navigate(..., { state: { result } })` to the Dashboard.
- **API (`services/api.js`)**: 
  - Uses `axios` for standard HTTP GET/POST requests.
  - Implements a unique `crypto.randomUUID()` to generate request IDs client-side, which are passed to the backend via the `X-Request-ID` header.
  - Uses native browser `EventSource` to subscribe to the backend's `/api/progress/stream` SSE endpoint to drive the real-time `ValidationPipeline` progress bar.

## 5. Components
The Dashboard is heavily componentized into "Intelligence Sections":
- `MarketSection.jsx`: Displays Market Attractiveness, KPIs, and Strategic Opportunities.
- `CustomerSection.jsx`: Displays Customer Personas and Pain Points.
- `CompetitorSection.jsx`: Displays Competitive Landscape and Differentiation.
- `ComparisonSection.jsx`: Displays the Final Executive Strategy and Confidence Score.
- `WebSearchSection.jsx`: Displays Research Evidence and verified URLs.

## 6. Styling System
- **Tailwind CSS**: Used extensively for utility-first styling, layout (Flexbox/Grid), and responsive design.
- **Framer Motion**: Used for micro-animations, page transitions, and staggered card reveals to give the application a premium, executive feel.
- **Glassmorphism**: UI elements utilize translucent backgrounds with blur effects (e.g., `backdrop-blur-md`, `bg-white/5`).

## 7. Build Process
Run `npm run build` to compile the Vite application into static HTML/CSS/JS bundles suitable for CDN deployment (Vercel, Netlify, AWS S3).

## 8. Environment Configuration
Uses `.env` files (e.g., `VITE_API_URL`) to dynamically route API requests depending on the deployment environment (Localhost vs Production).
