> **VentureLens** is a production-grade, asynchronous, multi-agent intelligence platform designed to transform raw startup ideas into comprehensive, investor-ready due diligence reports. Powered by a decentralized Peer-to-Peer (P2P) agent mesh network, it researches, analyzes, and strategizes using live web data.

---

## 📖 1. Vision & Problem Statement

**The Problem:** Traditional startup validation is painfully slow, inherently biased, and heavily reliant on static, generic advice. Founders spend weeks piecing together market research, while investors waste hours evaluating fundamentally flawed business models. Generic LLMs hallucinate market data and lack the multi-step strategic reasoning required for deep due diligence.

**Why VentureLens Exists:** VentureLens automates the entire validation lifecycle. By orchestrating a decentralized **Peer-to-Peer (P2P) Agent Mesh**, VentureLens mimics a board of specialized experts (Market Analysts, Risk Assessors, Product Strategists). It continuously searches the live web for ground-truth data, cross-references claims, and generates a rigorously validated business model scorecard.

---

## 🌐 2. Platform Overview & Key Features

VentureLens isn't just an API wrapper; it's a deeply engineered orchestration platform.

- **🕸️ P2P Multi-Agent Engine**: Unlike linear agent chains that suffer from bottlenecking, our Agent Mesh allows 8 specialized agents to execute concurrently and share context graph-style. Built on `asyncio` and FastAPI background tasks.
- **🛡️ Guardrails & Validation Layer**: Every agent output passes through a `GuardrailManager` ensuring strict Pydantic v2 schema matching and factual consistency.
- **🧮 Startup Scoring Engine**: Dynamically calculates a `0-100` viability score based on industry-specific risk matrices generated by the AI mesh.
- **🤖 Vera AI Co-Founder**: An interactive chat interface powered by an in-memory **Qdrant Vector DB** (RAG pipeline), allowing founders to dynamically interrogate their generated reports via WebSockets.
- **📊 Workspace & Export**: An interactive React Workspace to manage reports, alongside one-click generation of PDF pitch decks and `python-pptx` presentations.

### End-to-End Intelligence Workflow

1. **Idea Submission**: User submits an idea via the Dashboard.
2. **Phase 1 (Research)**: The **Web Search Agent** aggregates live market data via Tavily.
3. **Phase 2 (Analysis)**: **Market, Customer, and Competitor Agents** run concurrently to extract structured data.
4. **Phase 3 (Synthesis)**: **SWOT, MVP, GTM, and Risk Agents** generate actionable strategies.
5. **Phase 4 (Scoring)**: The Scoring Engine finalizes the JSON report.
6. **Workspace**: User navigates the interactive report or queries the Vera RAG pipeline.

## 📁 4. Project Structure

VentureLens is organized into deeply decoupled modules following service-oriented architecture principles.

```text
VentureLens/
├── backend/
│   ├── api/             # FastAPI REST & WebSocket Routes
│   ├── agents/          # 10 Specialized LLM Agents (e.g., market_agent.py, risk_agent.py)
│   ├── contracts/       # Pydantic v2 Schemas enforcing rigid data shapes
│   ├── crew/            # Orchestrator (orchestrator.py manages async mesh)
│   ├── guardrails/      # Manager ensuring factual & schema consistency
│   ├── rag/             # Qdrant Vector Store integration & Embeddings
│   ├── export/          # PDF (fpdf2) and PPTX (python-pptx) generation
│   └── database/        # SQLAlchemy ORM, Alembic migrations, SQLite bindings
│
├── frontend/
│   ├── src/components/  # Modular React UI (Report Sections, Charts, Modals)
│   ├── src/pages/       # Route Views (Dashboard, Workspace, VeraChat)
│   └── src/contexts/    # React Context APIs for state management
│
└── docs/                # Extended architectural documentation
```

## 💻 5. Installation, Configuration & Deployment

### Prerequisites
- Python 3.10+
- Node.js 18+

### Environment Configuration (`.env`)
```env
OPENROUTER_API_KEY=your_openrouter_key
TAVILY_API_KEY=your_tavily_key
SECRET_KEY=your_secure_random_string
```

### Local Development
**Backend:**
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
python -m uvicorn app:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

### Deployment
- **Backend (Render / Railway):** Deploy using `uvicorn app:app --host 0.0.0.0 --port $PORT`. Ensure SQLite volume persistence or swap to PostgreSQL.
- **Frontend (Vercel / Netlify):** Set build command to `npm run build`, output to `dist`. Set `VITE_API_BASE_URL` to the deployed backend URL.
